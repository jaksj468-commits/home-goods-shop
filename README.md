# PEX — Product Exchange

面向中国市场的商品展示、精选推荐、推广与交易平台。使用 HTML、CSS、JavaScript 构建，可部署到 GitHub Pages。

## 本地预览
直接用浏览器打开 `index.html`。

## 发布
本项目通过 GitHub Actions 自动发布。提交到 `main` 分支后，工作流会自动构建并部署 GitHub Pages。可在仓库 Actions 页面查看部署状态，并在 Settings → Pages 查看站点地址。

## 推广链接
编辑 `products.js`，将每个商品的 `affiliateUrl` 替换成自己的真实商品推广链接。当前示例链接仅用于演示。
