# PEX — Product Exchange

A product discovery, curated recommendation, promotion, and referral website. Built with HTML, CSS, and JavaScript and deployable to GitHub Pages.

## Preview locally

Open `index.html` in your browser.

## Deployment

This project is automatically deployed through GitHub Actions. Every push to the `main` branch triggers the workflow to build and deploy the GitHub Pages site. Check the Actions tab for deployment status and Settings → Pages for the published site URL.

## Affiliate links

Edit `products.js` and replace each product's `affiliateUrl` with your own valid product referral link. The current example links are for demonstration only.
